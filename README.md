# Klas Kayoko

Klas Kayoko adalah web belajar sederhana bertema komik sekolah Jepang, berisi navigasi materi untuk SD kelas 1–6, SMP kelas 7–9, dan SMA kelas 10–12. Pengunjung dapat mengubah profil, mengganti foto profil, serta menyimpan foto ke galeri.

## Menjalankan

Buka `index.html` di browser. Tidak membutuhkan proses build atau dependensi. Google Fonts digunakan untuk tipografi; jika sedang offline, browser memakai font cadangan.

## Fitur

- Beranda responsif dengan ilustrasi sekolah bergaya manga.
- Materi dikelompokkan menurut jenjang dan kelas.
- Profil yang dapat diedit, termasuk nama, kelas, catatan, dan foto.
- Galeri foto yang dapat ditambah dan dihapus.
- Animasi transisi halaman bergaya komik; menghormati preferensi reduced motion.
- Profil dan foto tersimpan di `localStorage` browser yang digunakan.

Catatan: materi saat ini berupa katalog topik pengantar, bukan modul pembelajaran lengkap. Foto disimpan di browser/perangkat lokal dan kapasitasnya mengikuti batas penyimpanan browser.
